# PawMatch

Application iOS de mise en relation entre de futurs adoptants et des animaux de refuge : on « swipe » les animaux proches de chez soi, un score de compatibilité explique les points forts et les points de vigilance, et un like envoie une demande au refuge.

```bash
brew install xcodegen
xcodegen generate
open PawMatch.xcodeproj
```
